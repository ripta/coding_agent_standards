## On Demand

The plugin's `standards-on-demand.py` hook names these the first time a session reads or changes a `.svelte`, `.css`,
`.html`, `.jsx`, or `.tsx` file. A session that only touches backend code never loads them. Read them before UI work
when no hook runs.
