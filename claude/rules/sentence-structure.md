# Sentence Structure

Applies everywhere: commit messages, PR summaries, code comments, docs, spec
prose, and chat.

- Write short sentences. One idea per sentence.
- Do not stack clauses. When a sentence is doing two jobs, split it into two
  sentences with a period.
- Prefer a period over a comma-plus-subordinate-clause that chains a second
  independent idea.
- Say the concrete thing plainly instead of packing qualifiers into one long
  sentence.
- Avoid overly complex sentences. Split a sentence that has multiple
  subordinate clauses.
